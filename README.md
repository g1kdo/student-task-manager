# Student Task Manager

## Overview

Student Task Manager is a simple Java console application that helps users manage their daily tasks. The project was developed as part of an Agile and DevOps assessment and demonstrates basic software development practices such as sprint planning, version control, testing, and continuous integration.

## Features

* Add a new task
* View all tasks
* Mark a task as completed
* Delete a task
* Basic console logging
* Health check message

## Technologies

* Java 21
* JUnit 6
* Git
* GitHub Actions

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Run the `Main` class.

## Agile Process

### Sprint 1

* Add Task
* View Tasks
* Unit testing
* GitHub repository setup

### Sprint 2

* Complete Task
* Delete Task
* Console logging
* Health check
